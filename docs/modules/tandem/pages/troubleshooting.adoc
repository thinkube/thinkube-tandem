= When something goes wrong
:page-type: how-to

.TL;DR
Find what you see in the first column; the second says why it happens and the third what to press. If a page shows a symbol whose meaning is not written next to it, that is a defect in Tandem, not in your reading.

== Why this is one sentence

Every message Tandem shows says what happened in one sentence, and the page you are on offers the press that changes it. This table is for the cases where the press is not on the page you are looking at.

== By hand, and what is happening underneath

[cols="1,1,2"]
|===
|What you see |Why |What to do

|The sidebar shows "Which project / repository…"
|Your workspace has more than one folder and no repository is chosen yet
|Press *Choose repository…*; the choice is remembered per workspace.

|The strip refuses *Build these N* with "the signature does not match"
|The promises changed after you signed them, so what would run is not what you approved
|Open *what it will do*, read the promises again, and press *Build these N* again.

|"No forge is configured"
|The repository has no remote Tandem can push to
|Add a remote. github.com remotes use the `gh` CLI; Thinkube Git needs `thinkubeTandem.giteaToken`.

|A line under a promise shows ✗
|A check ran against the delivered code and did not pass. This is the truth, not a glitch
|Press the check to read what it saw. Say what you want instead as a new line in the box; the delivery stays yours to refuse.

|"⛔ containment: … — reverted, unit failed"
|A worker wrote outside the files it declared
|The stray files were put back and the run stopped, naming the piece of work. Press *Run it again*.

|"REFUSED to write the store: secret-shaped content …"
|A line you wrote, or a promise, contains something that looks like a credential
|Remove it from the text. The space stays as it is on the page.

|*Build these N* says documentation is needed
|Every thing carries a documentation promise, and neither its page nor *Not needed* is there
|Press *Not needed* on the documentation promise with your reason, or let the page be built. xref:from-sentence-to-promise.adoc#_documentation_is_part_of_every_thing[Documentation is part of every thing].

|A card says *needs you* and nothing moves
|A worker stopped on a question only you can answer, about what you want
|The card offers a box and *Send*. The status bar says *needs an answer* until you do.

|"the reviewers are locked out, so none was started"
|The reviewers' browser could not sign in to the running product
|The lines they would have judged stay *not judged*, and nothing already proved is taken away. Open the address yourself and sign in. If that works, press *Run it again*; if it does not, the product is what to fix.

|A sentence reads *not judged* though its checks passed
|One of its lines could not be reached on the running product; the reviewer said what stopped it
|Read that line on the report. Blocked is never counted against the work.

|A line says "judged with no picture saved"
|The reviewer decided it but saved no picture
|The verdict stands; only the picture is missing. The reviewer's own words are on the line.

|You want an earlier cut's report or logs
|The page shows the cut you last chose
|Use the *Cuts* row at the top of the run page: every cut this space ran is there, with its *Report* and its *Run and logs*.
|===

== Limits

* A message quoted here is as the extension writes it at the version this page was written against; a word can move before the page does.
